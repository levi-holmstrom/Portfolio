## View & export to PDF

1. Open `index.html` in Chrome or Edge (double-click or drag into the browser).
2. **Ctrl+P** → Destination: **Save as PDF**
3. Enable **Background graphics** for the header tint and sidebar.
4. Margins: **Default** or **Minimum**; scale **100%**.

## Design notes

- **Fonts:** Source Serif 4 (headings) + Source Sans 3 (body) via Google Fonts (requires internet on first open; prints fine once loaded).
- **Palette:** Navy accent (`#1e3a5f`), soft gray sidebar, high contrast body text for readability.
- **Layout:** Two-column on screen/print; stacks on narrow screens.
